Seven Seas Material Flow — requirements
=======================================

This is a Node.js app, not a Python app: the packages below are installed by "npm install"
from package.json / package-lock.json (do not use pip). This file is only the checklist.

SOFTWARE TO INSTALL
-------------------
- Windows 10/11 (tested), or Linux/macOS
- Node.js 20 or newer (tested with 24.21.0)  — https://nodejs.org  (npm comes with it; tested npm 11.19.0)
- MySQL 8.x (tested 8.4.3) — easiest via Laragon (https://laragon.org), which includes it
- TallyPrime (optional) — only for the Tally sync of items, vendors and POs; server on port 9000
- A modern browser: Chrome or Edge

PORTS USED
----------
- 4000  app server (API, and the built website after "npm run build")
- 5173  website in development ("npm run dev")
- 3306  MySQL          — keep blocked from the network
- 9000  TallyPrime     — keep blocked from the network
- 4001  test server (only while "npm test" runs)
